使用教程与常见问题

1. 登录与账号
默认账号：admin，密码：admin123。首次登录后请在管理后台修改密码。

2. 添加资源
后台 -> 资源管理 -> 添加资源，填写标题、选择分类、上传文件、添加标签（可选）、填写描述。

3. 管理资源
后台 -> 资源管理 -> 编辑/删除已有资源。

4. 用户管理
后台 -> 用户管理 -> 添加/禁用/删除用户，可重置用户密码。

5. 存储路径设置
安装时在向导中设置，安装后可在 应用中心 -> 云资源 -> 设置 -> 配置 中修改。

6. 站点设置
后台 -> 站点设置 -> 修改站点名称、简介、关于我们。

❓ 常见问题

📝 描述支持哪些 Markdown 标签？
• 标题：# 一级标题 到 ###### 六级标题
• 加粗：**加粗文字**，斜体：*斜体文字*
• 列表：- 无序列表 或 1. 有序列表
• 链接：[文字](https://链接)
• 图片：![图片描述](/图片名.png)
• 代码：`行内代码` 或 ```代码块```
• 引用：> 引用内容

🌐 关于我们（首页）支持哪些 HTML 标签？
• 标题：<h1>...</h1>
• 段落：<p>...</p>
• 加粗：<strong>...</strong>
• 链接：<a href="...">...</a>
• 图片：<img src="/图片名.png" style="max-width:100%;">

🖼️ 图片不显示怎么办？
① 确认图片已放入 上传目录
② 图片路径使用 /图片名.png（不要加 uploads 前缀）
③ 建议用英文+数字命名，避免中文乱码
④ 刷新页面（Ctrl+F5 强制刷新）

📂 应用更新后显示/下载出问题？
• 应用更新时，上传目录和数据库不会被覆盖
• 若更新后资源不显示，检查上传目录路径是否变更
• 建议更新前备份数据库（/volx/@appdata/cloud-resources/resource.db）
