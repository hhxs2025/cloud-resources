📖 使用教程 & 常见问题

1. 登录与账号
默认账号：admin / 密码：admin123
首次登录后请在管理后台修改密码

2. 添加资源
管理后台 → 资源管理 → 添加资源
填写标题、选择分类、上传文件、添加标签（可选）、填写描述

3. 管理资源
管理后台 → 资源管理 → 编辑/删除已有资源

4. 用户管理
管理后台 → 用户管理 → 添加/禁用/删除用户
可重置用户密码（重置后为 123456）

5. 存储路径设置
安装时在向导中设置，安装后可在 应用中心 → 云资源 → 设置 → 配置 中修改
修改后需在 应用设置 → 文件夹路径 中添加新目录，然后重启应用生效

6. 站点设置
管理后台 → 站点设置 → 修改站点名称、简介、关于我们

❓常见问题

📝描述支持哪些 Markdown 标签？
• 标题：# 一级标题 到 ###### 六级标题
• 加粗：**加粗文字**
• 斜体：*斜体文字*
• 列表：- 无序列表 或 1. 有序列表
• 链接：[文字](https://链接)
• 图片：![图片描述](/图片名.png)
• 代码：`行内代码` 或 ```代码块```
• 引用：> 引用内容

🌐关于我们（首页）支持哪些 HTML 标签？
• 标题：<h1>...</h1> 到 <h6>...</h6>
• 段落：<p>...</p>
• 加粗：<strong>...</strong> 或 <b>...</b>
• 斜体：<em>...</em> 或 <i>...</i>
• 列表：<ul><li>...</li></ul>（无序）或 <ol><li>...</li></ol>（有序）
• 链接：<a href="https://链接">文字</a>
• 图片：<img src="/图片名.png" style="max-width:100%;">
• 代码：<code>...</code>
• 引用：<blockquote>...</blockquote>

🖼️首页或资源详情页图片不显示怎么办？
① 确认图片已放入 上传目录（安装时设置，默认 /vol1/@appshare/cloud-resources/）
② 图片路径使用 /图片名.png
③ 检查图片文件名是否包含中文或特殊字符（建议用英文+数字）
④ 确认图片格式为 .png .jpg .jpeg .gif .svg .webp .ico .bmp .tiff
⑤ 刷新页面（Ctrl+F5 强制刷新）

📂上传图片或资源，在应用更新后显示/下载出问题怎么办？
• 应用更新时，上传目录和数据库不会被覆盖，数据安全
• 如果更新后资源不显示，检查 上传目录路径 是否变更
• 如果下载报错，检查 文件是否被误删除 或 权限是否正常
• 建议：更新前 备份数据库（/volx/@appdata/cloud-resources/resource.db）
• 如遇问题，在「管理后台 → 资源管理」重新编辑资源，确认文件路径正确
