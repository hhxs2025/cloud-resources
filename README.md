# 云资源 使用说明文档


## 📖一、 简介
云资源是一款专为飞牛 fnOS 开发的轻量级资源下载站点搭建工具。支持分类、标签、用户权限管理，仅登录用户可下载资源。适用于团队内部文件共享、资料归档、软件分发等场景。

## 🔐三、使用说明  
### 3.1  管理员操作指南  
#### 3.1.1登录管理后台  
登录后点击顶部导航「管理」进入后台。

#### 3.2分类管理  
- 在「资源管理」页面底部：
- 输入分类名称，点击「添加分类」
- 点击分类旁的 `×` 删除分类（会同时删除该分类下的所有资源）

#### 3.3标签管理  
- 在「资源管理」页面底部：
- 输入标签名称，点击「添加标签」
- 点击标签旁的 `×` 删除标签 

#### 3.4添加资源
- 点击「添加资源」展开表单：
- **资源标题**（必填）
- **选择文件**（必填，最大 1GB）
- **选择分类**（可选）
- **选择标签**（可选）
- **资源描述**（可选，支持换行）

点击「提交」完成上传。

#### 3.5.编辑资源
- 在资源列表中点击「编辑」：
- 修改标题、描述、分类、标签
- 点击「保存」生效

#### 3.6编辑/删除资源
在资源列表中点击[编辑]「删除」，确认后修改/删除资源文件及记录。

#### 3.7用户管理
- 在「用户管理」页面：
- **添加用户**：输入用户名、密码，可设置为管理员
- **启用/禁用**：禁用后用户无法登录
- **删除用户**：不可删除自己

#### 3.8站点设置
- 在「站点设置」页面：
- **站点名称**：显示在页面头部
- **站点简介**：显示在头部标题下方
- **关于我们**：显示在首页，支持 HTML 标签

HTML 示例：
```html
<h3>关于我们</h3>
<p style="text-indent:2em">云资源是一个专注于资源共享的下载站点。</p>
<ul>
  <li>📄 文档资料</li>
  <li>🛠️ 软件工具</li>
</ul>
```
